## Interpretation and remaining validation

- Cases08/10/13 expose the same application-level workflow defect; successful OCR is not correct classification. New v2 classification and domain/storage gates are tested with mocked responses. The updated prompt has NOT been live-retested against these images.
- Case06 is explicitly uncertain. Two attempts with a returned value do not demonstrate correctness, and the initial failure cannot be called unreadability without logs.
- Case09 uses a synthetic Segoe Print font, not genuine handwriting. All images are synthetic, cleanly constructed samples, not representative field photos.
- Case15 establishes one observed rejection of one embedded instruction, not universal prompt-injection immunity. The fixed provider endpoint, no-tools request, strict output validation and human confirmation are independent application safeguards.
- Retry counts for cases other than06 and provider error details are unavailable. Unknown/incorrect columns are not assumed empty.
- Next live smoke test requires explicit operator authorization: classify all15 independently in both workflows; retain exact raw outputs, latency/error codes and separate per-field ground truth. Include genuine handwritten/low-light/mobile-captured documents with consent before real-world reliability claims.
